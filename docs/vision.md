# Vision

`chi-tea-aye` is a C++20 SDL3 game prototype that runs in every current web browser.

The direction is an open-world game that plays and feels like GTA IV: a city to roam on
foot and by car, cars with weight and body roll, a chase camera, hazy light, and bodies
and traffic that react. It is built as a vertical slice first, keeping each module
small enough to replace or extend.

The project codename is technical and does not decide the final game title.
